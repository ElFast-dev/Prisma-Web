Qué verifica

  • Tiempo de derivación Argon2id y coincidencia de claves entre las dos bibliotecas.
  • Cifrado y descifrado AES-256-GCM con nonce de 96 bits, etiqueta de 128 bits y cabecera autenticada.
  • Contraseña incorrecta, archivo alterado, truncado y versión no compatible.
  • Que una restauración simulada fallida conserva intacto el estado anterior.

La simulación no sustituye las pruebas de transacciones SQLite/OPFS, cuota ni falta real de espacio.
