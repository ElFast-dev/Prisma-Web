SQLite SAH pool + SharedWorker

Prueba funcional de un SharedWorker coordinador y un Dedicated Worker propietario de SQLite, compartidos por varias pestañas en Brave Android.

Solo datos sintéticos. Esta prueba crea y elimina una base con nombre exclusivo de la herramienta. No toca datos personales ni la aplicación Prisma. Abre esta misma dirección en dos pestañas del mismo Brave y del mismo origen. No uses navegación privada.

Conexión compartida

Ambas pestañas deben mostrar exactamente el mismo ID del SharedWorker. Este coordinador envía las operaciones a un único Dedicated Worker, que es el propietario exclusivo de OPFS SAH pool. Cuando las dos pestañas estén conectadas, el contador debe indicar 2 conexiones.
