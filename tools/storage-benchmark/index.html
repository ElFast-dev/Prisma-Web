Limitaciones de la comparación

SQLite SAH pool funciona dentro de un Worker y no ofrece varias conexiones concurrentes normales a la misma base. El resultado de rendimiento no basta para elegirla: también debemos resolver el uso de varias pestañas. El benchmark elimina su propio VFS al terminar.

El tamaño/uso informado por navigator.storage.estimate() no se usa como cuota garantizada. No se mide memoria física exacta porque Brave puede limitar esos datos.

Limpiar restos de pruebas

Si una ronda se interrumpe o el navegador cierra el Worker, puedes eliminar exclusivamente la carpeta OPFS y las bases IndexedDB con el prefijo propio de este benchmark.
