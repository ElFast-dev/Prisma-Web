# Conceptos visuales heredados — Prisma

Esta carpeta conserva propuestas visuales creadas durante la etapa anterior de Prisma. Se mantienen para consulta y trazabilidad, no como especificaciones finales de la PWA.

Los SVG de Historial, Pendientes y ficha local pueden ayudar a revisar estructura, jerarquía, estados y lenguaje visual. Antes de reutilizarlos deben revalidarse:
- prioridad y recorrido real de cada pantalla;
- adaptación a navegador y PWA en Android;
- tamaños táctiles, zoom, texto grande y accesibilidad;
- estados reales de datos, carga, error y ausencia de conexión;
- sencillez y consistencia del sistema visual web.

## Qué no significa este archivo

- Las aprobaciones descritas pertenecen a la etapa anterior y no aprueban automáticamente la versión web.
- Las menciones a Compose, CI, commits Android o números como 0.4.0/0.5.0 son históricas.
- La existencia de una pantalla SVG no significa que esté implementada.
- No se trasladarán interacciones que dependan de APIs nativas sin rediseñarlas.

## Archivos conservados

Los SVG originales permanecen en esta carpeta sin alteraciones. Solo se usarán como referencias hasta que el propietario apruebe una revisión visual específica para la PWA.
