# Conceptos visuales MVP aprobados

Estos archivos SVG son referencias vectoriales editables dibujadas manualmente; no son imágenes generadas por IA ni pantallas implementadas.

- `prisma-mvp-personal-obsidiana.svg` y `prisma-mvp-personal-cuarzo.svg`: Personal MVP con cuatro accesos.
- `prisma-mvp-descubrir-obsidiana.svg` y `prisma-mvp-descubrir-cuarzo.svg`: búsqueda única «Buscar...» y lista continua.

Los títulos y pósteres de ejemplo son ficticios. La pestaña Descubrir utiliza la constelación de tres destellos aprobada.

Estos conceptos corresponden solo a las primeras versiones del MVP. La experiencia completa posterior conserva cinco accesos en Personal (incluida Estadísticas) y el Feed avanzado de Descubrir según el Roadmap.
El texto «Buscar...» es genérico por diseño. El alcance funcional del MVP sigue limitado a películas; las series se incorporarán en una etapa futura cuando la experiencia de películas esté consolidada.
