# Guía de iconografía — Prisma

**Estado:** inventario de vectores heredados; revisión PWA pendiente.

Los SVG se seleccionaron durante la etapa anterior. Se conservan como referencias, pero no se consideran un sistema web aprobado hasta validar cada uso en la interfaz PWA.

El engranaje de Ajustes tiene seis dientes en el vector actual. Debe verificarse su legibilidad y pertinencia junto con la navegación real.

## Reglas para una futura aprobación web

- Comprobar legibilidad en tamaños móviles y con zoom.
- Mantener etiquetas accesibles; los iconos informativos necesitan nombre accesible.
- Los iconos decorativos no deben anunciarse a tecnologías de asistencia.
- El área táctil se define por el control y no por el tamaño del dibujo.
- Evitar duplicados por tema si CSS puede aplicar el color.
- No crear iconos para acciones o pantallas que todavía no existan.
